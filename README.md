# Erfan Riazati — Portfolio

A light, pastel portfolio exploring robotics, safe autonomy, control, research, and teaching.

**Live site:** https://erfanrzt.github.io/ReadMe/

## Run locally

No build step or package installation is needed. Serve this directory with `python -m http.server 8000` and open http://localhost:8000.

## Edit

- `index.html`: biography, projects, publications, journey, contact links.
- `style.css`: palette, typography, layout, responsive behavior.
- `script.js`: filters, simulation controls, email copy, subtle entrance effects.
- `resume.html`: printable professional résumé without home address or phone number.
- `assets/`: portrait and project imagery. See `CREDITS.md` for original sources.

GitHub Pages is configured to deploy from `main` at `/ (root)`. Changes pushed there publish automatically.

## Accessibility

Includes keyboard focus, skip navigation, semantic landmarks, image alternatives, live filter feedback, user-controlled simulation playback, and reduced-motion support. Core content remains available without JavaScript.
